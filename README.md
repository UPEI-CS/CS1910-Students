# CS1910 — Introduction to Computing

Course materials for CS1910 at UPEI. Everything you need for lectures, labs, homework, and
reading is here.

## What's here

| Folder | What it is |
|---|---|
| `book/` | The interactive textbook — one chapter per topic, in reading order. Start at [`book/README.md`](book/README.md). |
| `lectures/` | Lecture slides and the workbook notebooks used in class |
| `labs/` | Lab notebooks |
| `homework/` | Homework assignments |
| `case_study/` | End-of-term case studies |

Folders are numbered in teaching order: `01-Course-Orientation`, `02-Computational-Thinking`,
and so on. The same numbers line up across `lectures/`, `labs/`, and `book/`, so topic 08 is
`08-Functions` in all three.

## Working with the notebooks

You do not need to install anything. Open any `.ipynb` in Google Colab and it will run.

**Book chapters:** run the first code cell — the setup cell — before anything else. It draws
that chapter's figures and turns on "show me every result" mode, which the examples rely on.
Cells marked **▶ Interactive** wait for you to type something, so *Run All* skips them.
Cells that show a mistake on purpose are labelled as such.

**Getting your own copy:** in Colab, *File → Save a copy in Drive* before you start working,
or your changes will not be kept.
